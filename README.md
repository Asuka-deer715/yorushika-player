## 快速开始

1. 在 [Releases](https://github.com/Asuka-deer715/yorushika-player/releases) 下载 Windows x64 预览包，并完整解压。
2. 运行 `Yorushika.exe`，在「导入与整理」中选择自己持有的音乐或视频。
3. 点击播放栏打开完整播放页，在设置里调整字体、配色、歌词和开场动画。

已发布的 v0.1.2 包不需要安装 Node.js 或运行命令。请保留解压出的全部文件；该包未签名。音乐和视频默认保留在原位置，应用保存文件关联。

故事时间线以可拖动的横向视图串联作品、发行日期与故事线索，章节随浏览逐步呈现，动画可在设置中跳过。画廊按官方封面、联动、展览、个人收藏和同人图分类；个人图片保存在本机。应用提供中文、日文和英文界面，以及可在设置中重新查看的新手引导。

网易云歌曲目前仍通过嵌入式平台播放器试用，播放范围由平台决定；账号登录、直接在线音源播放和接入底部队列尚在开发，当前尚不可用。

导入视频支持普通视频文件或选择 B 站下载缓存目录。B 站缓存合并及内嵌图片／样式字幕需要 FFmpeg。当前打包脚本会把开发者指定的 FFmpeg 随包分发；已发布的旧预览包不一定包含它。普通用户不需要自行安装 `ffprobe`。

## 使用说明

- **本地 MV**：先导入音频和视频，在播放栏点击「MV」。一个已关联或明确同名的视频会直接播放；多个候选可选择。没有单独歌词的视频可沿用关联音频的歌词。
- **歌词与封面**：播放本地歌曲后，在「在线链接」搜索；本地歌词导入位于「设置」，MV 歌词偏移可在播放栏调整。网络服务可能变更或不可用。
- **B 站缓存**：选择下载目录，再选择转换结果的保存目录。原缓存保持不变；较大的视频需要足够的磁盘空间。
- **内嵌字幕**：在播放页选择字幕轨道。图片及 ASS／SSA 字幕首次会生成本地缓存，处理时间取决于视频时长、分辨率和电脑性能；视频本身不会被修改。特殊字体的 ASS 效果可能受本机可用字体影响。
- **桌面歌词**：点击播放栏的“词”按钮显示或关闭；歌词背景透明，可在浮窗外观中切换横排或竖排。
- **歌词书签**：播放页可以收藏当前歌词；侧栏“留住的一句”轮换展示，点击进入管理页播放或移除。
- **播放栏个性化**：在“设置 → 播放”中可设置进度滑块图片、轨道颜色、频谱及呼吸光晕；音量按钮展开竖向控制。
- **侧栏**：点击侧栏顶部的菜单按钮可收起或展开。
- **画廊**：可在“我的收藏”或“同人图”中添加图片；官方图片首次展示需要网络，成功获取后缓存在本机。
- **数据位置**：打包版默认使用当前用户的应用数据目录；开发版使用项目内 `.runtime/`。移动源文件后需要重新关联。

## 开发

需要 Node.js 24+。以下命令使用各用户系统的默认位置；开发目录和缓存可按个人环境配置。

```powershell
npm install
npm start
npm test
# 打包前，将 YORUSHIKA_FFMPEG 指向本机已有的 ffmpeg.exe
$env:YORUSHIKA_FFMPEG = "<你的 ffmpeg.exe 完整路径>"
npm run package:win
```

源码按功能组织：`src/desktop/` 包含播放、歌词、歌单、作品、视频和设置等界面模块；`src/main/` 包含媒体库、收藏、在线服务、字幕和窗口管理；`src/shared/` 保存共享类型与工具。`scripts/` 和 `tests/` 分别存放构建脚本和测试。

`start.cmd` 仅用于源码开发。Windows 用户也可以使用本机编译的 `Yorushika-Dev.exe` 无命令行启动源码版；该启动器需要本机 Node.js 和项目开发依赖，不是普通用户的应用包。启动器源码位于 `scripts/source-launcher.cs`，普通用户请使用 Releases 中的完整应用包。项目内 `font-candidates/`、`.runtime/`、`.local-electron.json` 和用户媒体不提交仓库。

源码界面目前引用的官方标志和专辑图像位于 `src/renderer/yorushika-official-mark.svg` 与 `src/renderer/yorushika-official-album.jpeg`，这两项不包含在公开仓库中；在确认使用权限后需自行提供。字体候选同样不随源码仓库发布。缺少这些素材时，界面或开场画面可能不完整。
